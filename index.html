01 — UNDERSTANDING THE WEB

Dasturlash aslida nima?

Dasturlash — kompyuterga muayyan vazifani qanday bajarishni aniq ko‘rsatmalar orqali tushuntirish jarayoni. Dasturchi faqat kod yozmaydi: u muammoni tahlil qiladi, yechim tuzadi, sinaydi va xatolarni tuzatadi.

01 ◇

Muammoni tushunish

Foydalanuvchiga nima kerak? Dastur qaysi vazifani bajarishi kerak? Avval shu savollarga javob topiladi.

02 ⌘

Algoritm va kod

Yechim bosqichlarga bo‘linadi. Algoritm — bu vazifani bajarish tartibi, kod esa uni dasturlash tilida ifodalashdir.

03 ↗

Sinash va natija

Dastur ishga tushiriladi, natija tekshiriladi. Xato topilsa tuzatiladi va qayta sinovdan o‘tkaziladi.

Masalan, onlayn do‘konda «Sotib olish» tugmasi shunchaki rasm emas. U foydalanuvchi harakatini qabul qilib, buyurtma jarayonini boshlashi kerak.

02 — THE STRUCTURE

HTML sahifaga shakl beradi.

HTML — HyperText Markup Language. U veb-sahifadagi sarlavha, matn, rasm, havola va tugmalar kabi elementlarni belgilaydi. HTML dasturlash tili emas, balki belgilash tilidir.

<h1>Salom, dunyo!</h1> <p>Bu mening saytim.</p> <button>Boshlash</button>

Koddagi teglar brauzerga qaysi elementni yaratish kerakligini bildiradi. O‘ng tomonda kodning sahifaga qanday aylanishini ko‘r.

04 — LOGIC & INTERACTION

JavaScript sahifaga mantiq beradi.

JavaScript — brauzerda ishlay oladigan dasturlash tili. U hodisalarni qabul qiladi, ma’lumotlarni qayta ishlaydi va sahifa elementlarini o‘zgartiradi.

Masalan, tugma bosilganda hodisa yuz beradi. Kod shu hodisaga javob qaytaradi va foydalanuvchi ko‘radigan natija o‘zgaradi.

button.addEventListener( 'click', () => { count++; updateScreen(); } );

Quyidagi demo tugmasini bosib, hodisa va natija o‘rtasidagi bog‘lanishni kuzat.

06 — THE INTERNET JOURNEY

Sayt ochilganda nima sodir bo‘ladi?

Brauzer manzilni oladi, domen nomi DNS orqali IP manzilga aniqlanishi mumkin, so‘ng serverga tarmoq so‘rovi yuboriladi. Server javob beradi, brauzer esa kelgan resurslarni qayta ishlaydi.

Bu soddalashtirilgan model. Haqiqiy saytlarda keshlash, CDN, xavfsizlik tekshiruvlari, API so‘rovlari va boshqa bosqichlar ham bo‘lishi mumkin.

07 — DATA BECOMES A STORY

Grafika — bu ma’lumotning tili.

Grafika faqat rang yoki bezak emas. U murakkab ma’lumotlarni ko‘rish, solishtirish va tushunishni osonlashtiradi. Grafik elementning shakli, o‘lchami, joylashuvi va harakati ma’no yetkazishi mumkin.

Interfeys grafikasi

Ikonlar, menyular, diagrammalar, xaritalar va boshqaruv elementlari foydalanuvchiga tizimni tushunish va boshqarishga yordam beradi.

Harakatli grafika
